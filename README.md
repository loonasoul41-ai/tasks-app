# Task Manager - Сайт для управления заданиями

🎯 **Простой и удобный менеджер задач** для организации вашей работы, учебы и личных дел.

## ✨ Основные возможности

- ✅ **Добавление заданий** - создавайте новые задачи с названием, описанием и дедлайном
- 📂 **Категоризация** - распределяйте задачи по типам (Работа, Учеба, Личное, Здоровье)
- 🔄 **Управление статусами** - отслеживайте прогресс (К выполнению → В процессе → Готово)
- 📊 **Статистика** - видьте общую статистику и процент выполнения
- 🎯 **Фильтрация** - быстро находите нужные задачи по статусу
- 💾 **Локальное хранилище** - все данные сохраняются в браузере
- 📱 **Адаптивный дизайн** - работает на ПК, планшетах и мобильных телефонах

## 🚀 Быстрый старт

## 📝 Как использовать

### Добавление задания
1. Заполните название задания (обязательно)
2. Добавьте описание (опционально)
3. Выберите категорию
4. Установите дедлайн (опционально)
5. Нажмите "+ Добавить задание"

### Управление заданием
- **Начать** - переместить задачу в статус "В процессе"
- **Готово** - отметить как выполненную
- **Удалить** - удалить задачу

### Фильтрация
Выбирайте между фильтрами:
- **Все** - все задачи
- **К выполнению** - новые задачи
- **В процессе** - текущие задачи
- **Готово** - завершенные задачи
